# Инструкция по разметке YouTube курса жестового языка

## Контекст

У нас есть 33 видео курса русского жестового языка из Ижевска (1.9 ГБ).
Для обучения модели непрерывного распознавания жестов нужна разметка:
- Какой жест показывается
- В каком временном диапазоне
- Текст перевода

## Инструмент разметки

Создан скрипт `tools/annotate_video.py` для интерактивной разметки видео.

### Запуск

```bash
python tools/annotate_video.py "datasets/youtube/Курс русского жестового языка/001_Курс жестового языка, Урок 1.mp4"
```

### Управление

| Клавиша | Действие |
|---------|----------|
| Пробел | Play/Pause |
| ← / → | Перемотка ±1 секунда |
| Ctrl+← / Ctrl+→ | Перемотка ±5 секунд |
| M | Установить маркер начала жеста |
| N | Установить маркер конца жеста |
| T | Ввести текст перевода |
| S | Сохранить текущий сегмент |
| R | Сбросить текущий сегмент |
| Q / ESC | Выход |

### Процесс разметки

1. **Запустите видео** (Пробел)
2. **Найдите начало жеста** (пауза перед движением руки)
3. **Нажмите M** - установится маркер начала
4. **Досмотрите до конца жеста**
5. **Нажмите N** - установится маркер конца
6. **Нажмите T** - введите текст перевода (например: "Привет", "Спасибо", буква "А")
7. **Нажмите S** - сегмент сохранится в JSON файл
8. **Повторите** для следующего жеста

### Формат сохранения

Разметка сохраняется в JSON файл рядом с видео (например, `001_Курс жестового языка, Урок 1.json`):

```json
[
  {
    "start_frame": 150,
    "end_frame": 210,
    "start_time": 5.0,
    "end_time": 7.0,
    "text": "Привет",
    "timestamp": "2026-10-20T12:34:56"
  },
  ...
]
```

## Рекомендации по разметке

### Что размечать

1. **Изолированные жесты** - отдельные слова и буквы
2. **Фразы** - устойчивые выражения
3. **Дактилологию** - буквы по буквам
4. **Числа** - числовые жесты

### Как размечать

- **Точность**: старайтесь точно отмечать начало и конец жеста
- **Контекст**: если жест повторяется несколько раз - размечайте каждый повтор
- **Текст**: используйте русский текст, как он звучит в курсе
- **Сомнения**: если не уверены в переводе - оставьте комментарий в тексте

### Примеры разметки

```
Видео: Урок 1 - Приветствие
- 0:05-0:08: "Привет"
- 0:10-0:13: "Здравствуйте"
- 0:15-0:18: "Как дела"
- 0:20-0:25: "Меня зовут Александра"
```

## Следующие шаги после разметки

1. **Собрать все JSON файлы** в один датасет
2. **Извлечь landmarks** из размеченных сегментов через MediaPipe
3. **Создать windows** с фиксированной длиной (22 кадра, шаг 5)
4. **Обучить модель** continuous sign language recognition
5. **Протестировать** на новых видео

## Альтернатива: полуавтоматическая разметка

Если ручная разметка займёт слишком много времени, можно:

1. **Использовать pre-trained модель** Slovo (MViTv2) для первичной детекции
2. **Разметить только начало и конец** жестов (без текста)
3. **Автоматически извлечь текст** из субтитров видео (если есть)
4. **Вручную проверить** и исправить автоматическую разметку
