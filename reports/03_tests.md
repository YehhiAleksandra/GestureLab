## 2. Факты и замеры (локальные, 2026-10-19)

- **B22 (critical, окружение):** MediaPipe 0.10.14 на Windows не загружает графы, если путь site-packages содержит не-ASCII: `FileNotFoundError: .../mediapipe/modules/hand_landmark/hand_landmark_tracking_cpu.binarypb` при том, что файл существует. Проверка: та же установка, скопированная в ASCII-путь, инициализирует Hands и FaceDetection без ошибок. Причина — C++-часть открывает пути как ANSI, а Python передаёт UTF-8. Следствие: **venv проекта нельзя держать внутри `D:\ДляГлухихAi\...`**; рабочий venv создан в `D:\venvs\gesturelab` (Python 3.11.9, mediapipe 0.10.14, cv2 5.0.0, pytest 9.1.1). CI на ubuntu не затронут (пути ASCII).
- cv2 в свежей установке резолвится в **5.0.0** → кириллица HUD читается (замер фазы 1: на 4.12 были «?????»). Риск B2 остаётся только для окружений со старым пином 4.x.
- Реальных записей `sessions/` на машине нет → таблица по реальным сессиям отсутствует (ТЗ §5.5); тесты на фикстурах выполнены полностью.
