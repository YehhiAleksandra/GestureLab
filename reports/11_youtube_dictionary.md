# Этап 6: YouTube-словари → расширение словаря модели

Дата: 2026-10-22

## Цель

Расширить словарь распознавателя РЖЯ за счёт данных из YouTube/Rutube-каналов с
изолированными жестами. Два направления: (A) дообучение на совпадающих словах,
(B) добавление новых классов в голову модели.

## Источники данных

| Источник | Тип | Видео | Жестов | Уникальных слов | Совпадение с Slovo |
|----------|-----|-------|--------|-----------------|-------------------|
| ARK (ARKMEDIA-SPB) | YouTube словарь, OCR-метки | 15/33* | 2480 | 1083 | 8% (54) |
| Курсы РЖЯ | YouTube плейлист, слайд-метки | 31/33* | 172 | 123 | 44% (27) |
| Rutube словарь | 1 видео = 1 слово | 188/894* | 86** | 85 | 22% (198 по заголовкам) |

\* Извлечение продолжается в фоне.
\** В обучение B пошли первые 86 из 188 извлечённых.

### Особенности

- **ARK**: OCR tesseract по белой подписи в углу кадра. Агрессивная нормализация
  (`norm_ocr`): удаление цифр, однобуквенных префиксов, мусора без гласных.
- **Курсы**: слово читается с экранного слайда, отрезки по IOU маски подписи.
- **Rutube**: чистейшие метки — слово в заголовке, одно видео = один жест.

Только совпадающие 119 слов, без добавления новых классов.

| Метрика | Baseline | Phase A |
|---------|----------|---------|
| Slovo test top-1 | 63.9% | 63.4% |
| Slovo test top-5 | 85.4% | 84.9% |
| YouTube top-1 | — | 100% |
| Классов | 1001 | 1001 |

Вывод: YouTube-данные усвоены (100%), но cross-signer обобщение на Slovo не улучшилось.
Ожидаемо: всего 212 совпадающих сэмплов не перевешивают 15300 Slovo.

## Результаты Phase B (add-new, 80 эпох)

С добавлением 1017 новых классов из YouTube/Rutube данных.

| Метрика | Baseline | Phase B |
|---------|----------|---------|
| Slovo test top-1 | 63.9% | **61.9%** |
| Slovo test top-5 | 85.4% | **83.1%** |
| YouTube top-1 | — | **100%** |
| Классов | 1001 | **2018** |

Кривая обучения (top-1 на Slovo test, OneCycleLR):
```
ep  5: 62.6%  (random head, высокий loss 3.0)
ep 15: 58.9%  (дно — модель учит 1017 новых классов)
ep 35: 60.8%  (восстановление)
ep 65: 62.0%  (плато)
ep 80: 61.9%  (финал)
```

**Итог**: словарь удвоен (1001→2018), потеря на Slovo test всего 2 п.п. (63.9%→61.9%).
YouTube-данные усвоены полностью.

## Изменения в коде

- `tools/finetune_youtube.py`: исправлен баг с повторным чтением npz в цикле
  (`d['frames']` → eagerly loaded `frames = d['frames']`), вызывавший OOM.
- `tools/rt_dictionary.py`: новый скрипт извлечения из Rutube-словаря
  (894 видео, формат «1 видео = 1 слово»).
- `tools/live_translator.py`: модель по умолчанию → `slovo_signnet_holistic_yt.pt`.
- `models/slovo_signnet_holistic_yt.pt`: 2018 классов, holistic, 10.1 MB.

## Баги исправленные

- **B29 OOM при загрузке npz**: `load_youtube()` обращалась к `d['frames']` (lazy NpzFile)
  внутри цикла, каждый раз перечитывая весь массив с диска. При 2480 итерациях это вызывало
  фрагментацию памяти и `_ArrayMemoryError`. Фикс: `frames = d['frames']` перед циклом.
- **B30 Rutube BrokenProcessPool**: MediaPipe workers + CUDA training = OOM.
  Перезапуск с `--workers 1`.
