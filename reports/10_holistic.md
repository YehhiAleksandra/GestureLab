# 10. Поза и лицо в распознавании + метрика «смысл передан» (2026-10-22)

Продолжение `09_everyday_translator.md`. Задача от Вадима: «внятно переводить жесты в привычный
текст». Все числа получены 2026-10-21/22 скриптами ниже; JSON — в `reports/evidence/`.

## Что изменилось

| Что | Файл | Суть |
| --- | --- | --- |
| Данные | `tools/slovo_holistic.py` | `karinversan/slovo-full-landmarks` (HF, MediaPipe Holistic): 20400 видео, 1 014 049 кадров, 1001 класс с `no_event`. Блоки качаются по одному, сжимаются в npz, parquet удаляется |
| Признаки | `slovo_model.py`, `live_signs.py` | кисти + 7 точек позы (плечи, локти, запястья, нос) + 10 точек лица (рот, глаза, брови). Всё в системе координат плеч — модель видит, *где* у тела показан жест. Форма рта — 2 отношения. Зеркальная аугментация с перестановкой левых/правых точек (`MIRROR`) |
| Обучение | `tools/train_slovo_seq.py --kind holistic` | вид признаков пишется в чекпойнт |
| Перевод | `tools/gloss_to_text.py` | в решётку идут вероятности («слово 62%»), LLM разрешено пропустить место, если ни один вариант не подходит |
| Оценка | `tools/eval_end_to_end.py` | судья `Qwen3-235B-A22B-Instruct-2507`: 0/1/2 — смысл не передан / суть / полностью |
| Живой режим | `tools/live_translator.py` | по `kind` из чекпойнта сам выбирает Holistic или Hands; `no_event` в топе — «не жест», в решётку не идёт |

## Сквозная оценка: 150 бытовых фраз, seed 0

Та же постановка, что в отчёте 09: 546 жестов, 389 из них от людей вне train, границы жестов
известны. «Смысл полностью» — доля фраз, где судья поставил 2; «суть» — 1 или 2.

| Вход LLM | старая модель (09) | hands_v2 | **holistic** |
| --- | --- | --- | --- |
| эталонные глоссы (потолок) | 92.7% / 100% | 92.7% / 100% | 92.7% / 100% |
| top-1 распознавателя | 25.3% / 48.7% | 22.0% / 51.3% | **34.7% / 57.3%** |
| решётка top-3 | 40.7% / 66.7% | 36.7% / 62.0% | **42.7% / 67.3%** |
| решётка top-3 с вероятностями | 41.3% / 66.7% | 39.3% / 65.3% | **46.7% / 69.3%** |
| + человек выбрал верный вариант клавишей 1–3 | 50.0% / 76.0% | 44.7% / 74.0% | **56.0% / 78.0%** |

chrF (holistic): потолок 50.7, top-1 35.1, решётка 40.3, решётка с вероятностями 39.6,
с выбором 43.8; сырые глоссы без LLM — 43.1. Жест верно с первой попытки 60.6%, в тройке 80.0%;
фраза целиком верна по top-1 в 18%. Прогон — $0.072.

**Как читать.** Почти половина фраз теперь передаётся по смыслу полностью без участия человека
(было четверть по top-1), а с одним нажатием 1–3 там, где модель ошиблась, — больше половины;
суть доходит в 7–8 фразах из 10. chrF и судья расходятся на «решётке с вероятностями»: chrF
штрафует перефразирование, судья — потерю смысла; для «чтобы любой понял» важнее второе.

## Проверки

- Гейт: `pytest -q` — **44 passed** (+2: раскладка holistic-кадра, зеркало меняет левые и правые точки).
- Дымовой прогон: `tools/live_translator.py --video <30 с урока> --no-tts` — holistic-модель,
  3 жеста, «серый получить вторник» → «Серый получил вторник.». Это урок со связной речью,
  поэтому мало жестов и низкая уверенность — ожидаемо (см. ограничения 09).
- NoWreck Claims Mode: `reports/evidence/nowreck_claims_holistic.json`, 14/14 подтверждено.
  Вызов `self.chat(...)` из `judge` NoWreck не видит (атрибутные вызовы не детектирует) —
  претензия убрана, проверена чтением кода.

## Исправлено по ходу

- Судья при 16 параллельных запросах (две оценки сразу) в ~30% ответов возвращал не цифру.
  Теперь цифра ищется регэкспом, непрочитанные ответы считаются отдельно (`judge_missing`),
  метрики — только по оценённым строкам, оценки идут последовательно. В прогонах hands_v2 и
  holistic `judge_missing = 0`. Прогон старой модели (`end_to_end_eval.json`) сделан до
  появления счётчика.

## Ограничения

- Старая модель обучена на другой выгрузке Slovo (1000 классов, 4998 тест-видео) — сравнение
  с ней ориентировочное; честный контроль — `hands_v2`.
- Связную речь по-прежнему не переводит: жест = отрезок, когда руки в кадре.
- Склейка клипов без коартикуляции — сквозные цифры оптимистичны.
- Судья — тоже LLM; его согласие с людьми не измерялось (ручной разметки нет). Потолок 92.7% на
  эталонных глоссах показывает, что он не придирается, но не доказывает точность.
- Наружу уходят только глоссы и готовая фраза (HF router, edge-tts). Видео и точки — на машине.
