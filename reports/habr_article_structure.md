## Структура статьи

### 1. Введение (лид-абзац) — 200 слов
**Цель:** Зацепить читателя, объяснить зачем проект

- Проблема: 10 млн глухих в России, переводчиков РЖЯ не хватает
- Что мы делаем: open-source переводчик русского жестового языка (РЖЯ) в реальном времени
- Честно: 22% точность — это не продукт, а исследовательский прототип
- Призыв: ищем энтузиастов для улучшения

### 2. Почему это сложно — 300 слов
**Цель:** Показать глубину проблемы

- РЖЯ ≠ калька с русского: другой порядок слов, грамматика
- Непрерывная речь: жесты сливаются, нет чётких границ
- Вариативность: разные исполнители, освещение, ракурсы
- Мало данных: нет больших размеченных датасетов РЖЯ

### 3. Наш подход — 400 слов
**Цель:** Объяснить техническую архитектуру

**Пайплайн:**
```
Видео → MediaPipe Holistic (59 точек) → CTC-модель → Глоссы → LLM → Русский текст
```

**Ключевые компоненты:**
- MediaPipe Holistic: 21 точка левой руки + 21 правой + 7 позы + 10 лица = 59 точек
- CTC (Connectionist Temporal Classification): для непрерывной последовательности жестов
- Beam search декодер с языковой моделью (LM)
- LLM (Gemma-4-31B) для перевода глоссов в естественный русский

### 4. Этапы развития — 800 слов
**Цель:** Показать итеративный процесс и прогресс

**Этап 1-10: База (ноябрь 2025)**
- Датасет Slovo: 1000 бытовых жестов, 15000 клипов
- Обучение классификатора на 1000 классов
- Accuracy: ~40% на изолированных жестах
- **Проблема:** это не перевод речи

**Этап 11-30: Непрерывное распознавание (декабрь 2025)**
- Переход на CTC-модель для непрерывной речи
- Beam search декодер, языковая модель
- N-best гипотезы → LLM → выбор лучшей
- Recall: ~12% на фразах

**Этап 31-40: Расширение словаря (октябрь 2026)**
- Rutube-канал: 67 клипов с точными фразами
- SP-10: 830 клипов с фразами
- Расширение головы модели: 1000 → 3993 класса
- Recall: 14.3%

**Этап 41-44: Интеграция VOGinfo (ноябрь 2026)**
- VOGinfo: 1637 клипов по 89 новым словам
- Критическая ошибка: оценка на training data дала +200% (переобучение)
- Честная кросс-валидация: разделение train/eval 80/20
- **Результат: 22.3% recall (+87% к базе)**

### 5. Честные результаты — 300 слов
**Цель:** Показать реальные метрики без приукрашивания

**Финальная оценка (этап 44):**
- Train: 1973 клипа (80% данных)
- Eval: 494 клипа (20% hold-out, модель не видела)
- Recall слов: **22.3%** (215/964 слов распознано верно)
- Статистическая значимость: p < 0.05

**Сравнение конфигураций:**
- Beam search + LM: 9.5% recall
- Beam search без LM: **22.3% recall** (лучше)
- **Вывод:** LM пока не помогает — нужно пересчитать на новые слова

### 6. Технический стек — 400 слов
**Цель:** Честно рассказать, что использовали

**Железо:**
- GPU: NVIDIA RTX 3060 Ti (8GB VRAM)
- RAM: 16GB
- Обучение: ~35 минут на 5 фолдов (1973 клипа × 40 эпох)

**Софт:**
- Python 3.11
- PyTorch 2.x с CUDA
- MediaPipe 0.10.14 (Holistic)
- OpenCV 5.0.0
- NumPy, SciPy

**ИИ-сервисы:**
- HuggingFace Inference Providers (Gemma-4-31B-it) для LLM-перевода
- HuggingFace Hub для хранения датасетов и моделей
- OpenRouter для альтернативных моделей (fallback)

**Датасеты:**
- Slovo: 15000 клипов, 1000 жестов (основной)
- SP-10: 830 клипов с фразами
- VOGinfo: 1637 клипов, 89 слов (YouTube-канал)
- Rutube: 67 клипов с точными фразами
- Parallel corpus: 2758 фраз (глоссы ↔ русский)

**Инструменты разработки:**
- Git, GitHub (приватный репо, планируется open-source)
- Qoder Desktop (AI-ассистент для разработки)
- pytest (203 теста)
- CI/CD: GitHub Actions

### 7. Использование ИИ в проекте — 200 слов
**Цель:** Честно показать роль ИИ

**Где ИИ помогал:**
- Написание кода: ~60% кода написано с помощью Qoder (GPT-4)
- Debugging: поиск ошибок в тестах, оптимизация
- Документация: генерация отчётов по этапам
- Анализ данных: визуализация метрик

**Где ИИ НЕ помогал:**
- Архитектурные решения: выбор CTC vs классификатор — человек
- Методология оценки: разделение train/eval — человек (после ошибки переобучения)
- Интерпретация результатов: почему LM не помогает — человек

**Вывод:** ИИ — инструмент, не замена. Критические решения принимает человек.
