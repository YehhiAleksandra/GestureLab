## 2. Устройство проекта

### Модули и поток данных

`gesturelab.py` — монолит в одном файле, синхронный цикл:

```
аргументы (--camera/--out/--fps/--no-preview-landmarks)
  → cv2.VideoCapture (CAP_DSHOW на win32), запрос 1280×720
  → цикл: cap.read() → BGR→RGB → hands.process() + face.process()
  → счётчики totals{frames, both, face} (КАЖДЫЙ кадр камеры)
  → если идёт запись и прошёл fps-гейт (1/--fps): дописать кадр в frames[]
  → отрисовка HUD (cv2.putText, кириллица!) и скелета рук
  → клавиши: r — старт/стоп сессии (input() в консоли), p — положение, q — выход
  → на стоп: собрать dict → json.dump в out_dir/<epoch_ms>_<жест>_<позиция>.json
```

`summarize.py` — отдельная утилита без зависимостей: `glob *.json` → агрегация по `(position[, gesture])`, взвешенная по `summary.frames` → таблица с вердиктом `>=90%` и опциональный CSV.

### Формат JSON-сессии (version 1)

```json
{
  "version": 1,
  "gesture": "да",
  "position": "грудь",
  "person": "В",
  "frames": [
    {"t_ms": 1234, "hands": 2, "face": true,
     "hand_landmarks": [[x0,y0,z0, ..., x20,y20,z20], [ ... ]]}
  ],
  "summary": {"frames": 300, "both_hands_pct": 95.0, "face_pct": 80.0}
}
```

- `hand_landmarks`: список по кистям, каждая — плоский вектор 21×3 (x,y,z нормированные), порядок «как в Android-версии» (со слов docstring `gesturelab.py:39`).
- `hands` — число кистей в кадре (0/1/2), `face` — булев флаг.
- Имя файла: `<epoch_ms>_<safe_name(жест)>_<позиция>.json`; исполнитель в имя файла НЕ попадает.

### Риски (не баги, но влияют на решения)

- **R1 (high).** PC использует legacy-API `mp.solutions.hands`, Android по ТЗ — MediaPipe **Tasks**. Это разные модели ландмарков; в объединённом датасете PC+Android возможен систематический сдвиг признаков. Проверить нельзя без исходников Android.
- **R2 (med).** Координата `z` у MediaPipe Hands — относительная глубина в масштабе `x`, несопоставима между положениями камеры («грудь» vs «шнурок»): этапу 1 нужна нормализация по положению.
- **R3 (low).** `model_selection=0` у face-детектора не прописан явно: смена дефолта в будущей версии mediapipe молча изменит метрику «лицо».
- **R4 (med).** Нет git, нет CI, нет тестов: любое изменение сейчас непроверяемо (правило конвейера из AGENTS.md не выполнено).
