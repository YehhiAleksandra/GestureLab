## Что сделано

### 1. Easy_sign модель (оценка завершена)
- **Файл**: `models/easy_sign/S3D.onnx` (37 MB)
- **Классов**: 1598 бытовых жестов RSL
- **Формат**: S3D video classification, вход [1, 3, 32, 224, 224]
- **Результат**: Работает для изолированных жестов, но не для непрерывной речи
- **Проблема**: На Bible RSL видео предсказывает "холод", "повар", "руководитель" — не подходит для библейской лексики

### 2. CSLR модель v2 (обучена на случайных признаках)
- **Файл**: `models/cslr_model_v2.pt` (60 MB)
- **Архитектура**: BiLSTM + CTC loss
- **Датасет**: 936 сегментов с pseudo-labels от Easy_sign
- **Loss**: 0.0007 (сошлась)
- **Проблема**: Обучена на `np.random.randn` признаках — выучила шум, не реальные паттерны

### 3. CSLR модель v3 (обучена на реальных landmarks)
- **Файл**: `models/cslr_model_v3.pt`
- **Датасет**: 929 сегментов с реальными MediaPipe landmarks (100 кадров × 126 признаков)
- **Словарь**: 347 уникальных жестов
- **Loss**: 3.47 (не сошлась)
- **Точность**: 0% на тестовых сегментах
- **Проблема**: Модель предсказывает одни и те же жесты повторно, не выучила паттерны

### 4. Извлечённые данные
- **Bible RSL видео**: 3 видео (71,520 кадров с hand landmarks)
  - `26RsAcQCVBA_landmarks.json` (67 MB) — Распятие
  - `9UdEIyOCQUY_landmarks.json` (26 MB) — Воскресение
  - `Qcc3VBT4VT4_landmarks.json` (90 MB) — Храм
- **Easy_sign predictions**: `26RsAcQCVBA_easy_sign.json` (936 предсказаний)
- **CSLR датасет**: `cslr_dataset_with_real_landmarks.json` (929 сегментов)

## Фундаментальные проблемы

### 1. Pseudo-labels шумные
Easy_sign предсказывает бытовые жесты ("спасибо", "новость", "холод") на библейском видео, где переводчик показывает религиозную лексику (Христос, Голгофа, воскресение). Модель учится на неправильных метках.

### 2. Изолированные жесты ≠ непрерывная речь
Easy_sign обучена на изолированных жестах (каждое слово отдельно). CSLR модель пытается предсказать непрерывную последовательность, но:
- Жесты переходят друг в друга
- Есть грамматика и контекст
- Нет размеченных данных связной речи

### 3. Мало данных для CSLR
929 сегментов с шумными метками недостаточно для обучения CSLR модели с 347 классами. Нужно тысячи примеров с правильными метками.

### 4. RSL ≠ русская грамматика
Даже если модель правильно распознает жесты, это не даст связный русский текст. RSL — отдельный язык со своей грамматикой.

## Что работает

### Slovo GRU модель (90.7% val accuracy)
- **Файл**: `slovo_model_pytorch.pt`
- **Датасет**: Slovo (2457 окон, 100 классов)
- **Результат**: 90.7% val accuracy на изолированных жестах
- **Ограничение**: Классификатор изолированных жестов, не переводчик

### Пошаговый переводчик (прототип)
- **Скрипт**: `tools/step_by_step_translator.py`
- **Подход**: Скользящее окно 22 кадра, классификация каждого окна
- **Результат**: 49 жестов за 60 секунд видео
- **Проблема**: Вадим забраковал — "набор слов, не связный перевод"

## Что НЕ работает

1. **CSLR модель v3** — 0% точность, loss не сошёлся
2. **Easy_sign на Bible RSL** — предсказывает бытовые жесты на религиозном контенте
3. **Перевод holy_sepulchre** — модель выдаёт случайные слова, не реальный перевод
