# 09. Бытовой переводчик РЖЯ → речь (2026-10-21)

Цель от Вадима: «для быта, а не для библейского» — жест → русская фраза → голос, понятные
любому. Все числа ниже получены 2026-10-21 этими скриптами; JSON — в `reports/evidence/`.

## Конвейер

```
камера → MediaPipe Hands → отрезок с руками = жест → SignNet (1000 слов Slovo, top-3)
       → глоссы → LLM на HF router (few-shot по корпусу глосс) → фраза на экране → edge-tts
```

| Этап | Файл | Результат |
| --- | --- | --- |
| 1. Распознавание жеста | `slovo_model.py`, `tools/train_slovo_seq.py`, `tools/slovo_sequences.py` | top-1 **58.7%**, top-5 **82.2%** (1000 классов, 4998 тест-видео) |
| 1a. то же, люди вне train | | top-1 **57.8%**, top-5 **82.3%** (1609 видео) |
| 2. Глоссы → фраза | `tools/gloss_to_text.py` | chrF **49.7** (gemma-4-31B) против 41.5 у сырых глосс; Qwen3-235B — 49.2 |
| 3. Сквозная оценка | `tools/eval_end_to_end.py` | см. ниже |
| 4. Живой режим | `tools/live_translator.py`, `live_signs.py` | работает на видеофайле; с камерой и живым жестящим не проверен |

Для сравнения: RGB-модель авторов Slovo (MViTv2) — 64.1% top-1. У нас только точки рук, без лица и тела.

## Сквозная оценка (этап 3)

Фразы — тестовая часть корпуса `Arseniy-Polyakov/parallel_corpus_russian_rsl_glosses`, где все
глоссы есть в Slovo (624 фразы, взято 150). Каждая глосса — случайный тест-клип Slovo этого
слова (389 из 546 клипов от людей, которых не было в train). Границы жестов известны.

| Вход LLM | chrF |
| --- | --- |
| эталонные глоссы (потолок распознавания) | 50.8 |
| сами эталонные глоссы без LLM | 43.1 |
| top-1 распознавателя | 31.6 |
| решётка top-3 (LLM выбирает осмысленный вариант) | 38.8 |
| top-3 + человек выбирает верный вариант клавишей 1–3 | 43.3 |

Жестов верно с первой попытки 56.8%, в тройке 78.9%; фраза целиком верна по top-1 в 13%.
Стоимость прогона на 150 фраз × 4 вызова — $0.054.

**Как читать.** Распознаватель ошибается примерно в каждом втором жесте, поэтому без помощи
фраза собирается редко. Решётка и выбор из трёх вариантов закрывают бо́льшую часть разрыва.
chrF занижает качество: эталоны корпуса — вольные пересказы («Надежда держится до последнего»
против «Надежда остаётся последней»).

## Ограничения (проверено, не предположение)

- **Связную речь не переводит.** На 40 с урока курса (учитель не опускает руки) вышло 3 жеста
  вместо десятков: границ жестов нет. Протокол живого режима — опускать руки между жестами
  или нажимать Пробел.
- В склейке клипов нет коартикуляции, поэтому сквозные цифры — оптимистичная оценка.
- Официальный split Slovo не полностью signer-independent: 92 человека есть и там, и там.
  Подвыборка незнакомых людей даёт почти те же цифры.
- Словарь — 1000 слов Slovo. Нет имён собственных, церковной лексики, дактиля в потоке.
- Наружу уходят только глоссы (HF router) и готовая фраза (edge-tts, Microsoft). Видео и точки
  остаются на машине. Для закрытого продукта нужен локальный TTS.
- LLM на неуверенной решётке иногда сочиняет («Август дважды талант замужем»).
