## Архитектура безопасности

### Как получаются токены

**HuggingFace:**
```python
from huggingface_hub import get_token
self.token = get_token()  # Берёт из ~/.cache/huggingface/token или HF_TOKEN env
```

**Использование:**
```python
req = urllib.request.Request(
    ROUTER, 
    body, 
    {'Authorization': f'Bearer {self.token}', ...}
)
```

✅ Токен **никогда не сохраняется в коде**, **не коммитится**, **не логируется**.

### Что НЕ попадает в репозиторий

1. **Веса моделей** (`*.pt`, `*.npz`) — только на диске D:
2. **Датасеты** (`datasets/`) — только на диске D:
3. **Видео** (`*.mp4`, `*.avi`) — только на диске D:
4. **Записи сессий** (`sessions/`) — только локально
5. **Кадры реальных людей** (`reports/ref/`, `reports/segments/`) — только локально
6. **Логи** (`*.log`) — игнорируются git
