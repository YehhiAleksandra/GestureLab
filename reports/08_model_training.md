# Отчёт: Обучение модели распознавания дактильной азбуки РЖЯ

**Дата:** 2026-10-20  
**Автор:** AI-ассистент

## Цель

Обучить модель для распознавания букв русской дактильной азбуки (РЖЯ) с камеры в реальном времени.

## Использованные датасеты

### 1. Bukva (ai-forever)
- **Размер:** 27 ГБ, 3757 видео
- **Классы:** 33 буквы + no_event = 34 класса
- **Лицензия:** CC BY-SA 4.0
- **Источник:** https://github.com/ai-forever/bukva
- **Обработано:** 1675 окон (MediaPipe нашёл руки в ~43% видео)

### 2. Slovo (hukenovs)
- **Размер:** 16 ГБ, 20400 видео
- **Классы:** 1001 жест (включая 33 буквы + слова)
- **Лицензия:** CC BY-SA 4.0
- **Источник:** https://github.com/hukenovs/slovo
- **Обработано:** 648 окон с буквами (после фильтрации)

### 3. Дополнительные ресурсы
- **signlang.ru:** Картинки дактильной азбуки (статичные, не видео)
- **Kazakh-Russian SL:** https://github.com/kurshakuz/krsl-recogniton (мало данных)

## Методика

1. **Обработка видео:** MediaPipe Hands извлекает 21 точку × 3 координаты = 63 признака на руку
2. **Формат:** Окна 22 кадра × 126 признаков (2 руки)
3. **Ресемплинг:** 30 FPS → 15 Hz, окна 1.5 сек, stride 0.75 сек
4. **Модель:** GRU (Gated Recurrent Unit), чистый numpy, BPTT + Adam
5. **Нормализация:** Координаты относительно запястья (инвариант к положению камеры)

## Результаты обучения

### Модель 1: Bukva только (baseline)
```
hidden=128, epochs=200, batch=32
Train: top-1 80.7%, top-3 95.1%
Val:   top-1 56.2%, top-3 81.5%
```

### Модель 2: Bukva + Slovo (объединённая)
```
hidden=128, epochs=100, batch=64
Train: top-1 80.7%, top-3 95.1%
Val:   top-1 48.6%, top-3 77.5%
```

### Модель 3: Bukva + Slovo v2 (увеличенная)
```
hidden=256, epochs=200, batch=64
Train: top-1 99.8%, top-3 100.0%  (переобучение)
Val:   top-1 51.4%, top-3 80.8%
```

### Модель 4: Bukva (детальный лог)
```
hidden=128, epochs=100, batch=32
Epoch 10:  Val top-1 39.0%
Epoch 30:  Val top-1 50.0%
Epoch 50:  Val top-1 46.9%
Epoch 100: Val top-1 51.4%
```

## Анализ

### Проблема переобучения
- Train accuracy достигает 99.8%, но Val только 51.4%
- Модель запоминает тренировочные данные вместо обобщения

### Причины низкого Val accuracy
1. **Мало данных:** 1675 окон (Bukva) + 648 (Slovo) = 2323 окна на 34 класса
   - В среднем ~68 окон на класс (минимум 31, максимум 85)
2. **Разные исполнители:** Bukva и Slovo записаны разными людьми
3. **Качество видео:** MediaPipe нашёл руки только в 43% видео Bukva
4. **Ограничения модели:** Простая GRU без регуляризации

### Что НЕ помогло
- Увеличение hidden (128 → 256): переобучение усилилось
- Добавление Slovo: Val accuracy упала (56.2% → 48.6%)
- Увеличение epochs: после 50 epochs начинается переобучение
