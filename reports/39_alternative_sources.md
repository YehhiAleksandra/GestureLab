## 4. План использования VOGinfo

### 4.1. Сегментация видео по словам

**Алгоритм:**
1. Парсить VTT-файл с таймингами
2. Для каждого вхождения слова из 89 найденных:
   - Извлечь тайминг начала и конца
   - Вырезать видео-сегмент (ffmpeg)
   - Обработать через MediaPipe (извлечь landmarks)
   - Сохранить в формат обучения

**Ожидаемый объём:**
- 89 слов × среднее количество вхождений = ~1000-2000 сегментов
- Каждый сегмент = 1 клип для обучения

**Время:**
- Сегментация 697 видео × ~17 минут = ~11,800 минут видео
- Обработка через MediaPipe: ~1 час на 100 видео (оценка)
- Итого: ~7 часов на извлечение landmarks

### 4.2. Интеграция в обучение

**Шаги:**
1. Извлечь сегменты для 89 слов
2. Добавить в `sp10_tune.json` как новые клипы
3. Расширить голову модели на 89 новых классов
4. Переобучить с новыми данными
5. Оценить на бенчмарке

**Ожидаемый результат:**
- Потолок поднимется с 55% до ~70-75% (194 + 89 = 283 из 353 фраз)
- Реальный прирост зависит от качества сегментации

### 4.3. Риски

1. **Качество сегментации:** субтитры показывают русский текст, а не глоссы. Жест может начинаться до/после появления субтитра.
2. **Контекст:** слово может быть частью фразы, а не изолированным жестом.
3. **Дубли:** одно слово встречается много раз — нужно дедуплицировать.
4. **Разметка:** нужно автоматически связать видео-сегмент со словом (weak label).

## 5. Альтернативные варианты

### 5.1. Записать свои видео с исполнителями

**Плюсы:**
- Точная разметка (isolated signs)
- Покрытие всех 102 отсутствующих слов

**Минусы:**
- Стоимость: ~50-100K руб
- Время: 1-2 недели на организацию
- Нужно найти 3-5 исполнителей

### 5.2. Искать дополнительные источники

**Идеи:**
- Другие YouTube-каналы на РЖЯ
- Онлайн-словари РЖЯ (http://www.rsl.ru/ru-3-2.html)
- VOGinfo другие видео (не из YouTube-SL-25)

**Риски:**
- Лицензионная чистота не гарантирована
- Время на поиск и обработку

### 5.3. Принять потолок 70-75%

Если VOGinfo даст 89 слов, это поднимет потолок до ~70-75%. Для продакшена это всё ещё мало, но для исследования — приемлемо.
