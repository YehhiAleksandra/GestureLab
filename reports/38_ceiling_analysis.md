# Этап 38 — Анализ потолка 55% и варианты его преодоления

Дата: 2026-11-03.

## 1. Ситуация

Модель достигла потолка **55,0%** (194/353 фразы бенчмарка). Это не баг алгоритма, а
структурное ограничение данных:

- **191 тип слова** отсутствует в голове модели (3993 класса)
- **189 из 191** нельзя выучить — для них нет клипов в обучающей выборке
- **Только 2 слова** из недостающих имеют клипы в train-сплите

## 2. Проверенные источники данных

### 2.1. SP-10 (SpreadTheSign)

**Скачано:** 1183 видео (830 train + dev + test)  
**Уникальных слов:** 1174  
**Покрытие недостающих:** 1 из 191 (слово есть в каталоге, но не скачано)

**Проблема:** GitHub-репозиторий SP-10 содержит только 1183 видео — это подмножество,
которое авторы включили в датасет. Полного каталога на 14K позиций в открытом доступе нет.

**Scraping spreadthesign.com:**
- HTTP 429 (Too Many Requests) — сайт блокирует автоматические запросы
- Поиск по словам не работает: "привет" → "Sorry, nothing found"
- Требуется обход блокировок (delays, User-Agent rotation, возможно Selenium)
- **Статус:** прототип скрипта написан (`experiments/sp10_search_missing.py`), но не работает

### 2.2. Rutube (канал 23691449)

**Фраз:** 67  
**Уникальных слов:** ~878 типов  
**Покрытие недостающих:** 0 точно, 3 по леммам (устать, мы, мой)

**Вывод:** Rutube не покрывает недостающие слова.

### 2.3. Slovo (датасет 1000 жестов)

**Уникальных слов:** ~999 типов  
**Покрытие недостающих:** 0 точно, 8 по леммам (местоимения и прилагательные)

**Вывод:** Slovo не покрывает недостающие слова.

### 2.4. Комбинированный охват

Rutube + Slovo вместе дают **9 из 185** недостающих лемм — это поднимет потолок
максимум до **55,3%** (195/353), что статистически незначимо.

## 4. Варианты преодоления потолка

### Вариант A: Расширенный scraping SpreadTheSign

**Что нужно:**
1. Обойти блокировку 429 (delays 5-10s, proxy rotation, Selenium/Playwright)
2. Понять структуру сайта: поиск не работает, нужна навигация по категориям
3. Найти 190 слов в каталоге SpreadTheSign
4. Скачать видео напрямую по URL (без scraping)

**Риски:**
- Нарушение ToS SpreadTheSign (автоматизированный сбор данных)
- Техническая сложность: сайт может использовать JavaScript rendering
- Время: 190 слов × 10s delay = ~32 минуты только на запросы

**Оценка:** 50% вероятность успеха, 2-3 дня работы

### Вариант B: Лицензия SpreadTheSign на полный каталог

**Что нужно:**
1. Связаться с European Sign Language Centre (владелец SP-10)
2. Запросить доступ к полному каталогу (14K позиций) для исследовательских целей
3. Получить лицензию (бесплатно для академического использования)

**Риски:**
- Время ожидания ответа (недели)
- Могут отказать в доступе к полному каталогу

**Оценка:** 70% вероятность успеха, но долго

### Вариант C: Запись своих видео с исполнителями

**Что нужно:**
1. Найти носителей РЖЯ (3-5 исполнителей)
2. Записать 190 видео (по одному на слово)
3. Разметить landmarks через MediaPipe
4. Добавить в обучающую выборку

**Риски:**
- Стоимость: аренда студии, оплата исполнителям (~50-100K руб)
- Время: 1-2 недели на организацию съёмки
- Качество: нужна согласованность с существующими данными SP-10

**Оценка:** 90% вероятность успеха, но дорого

### Вариант D: Принять потолок 55%

**Что это значит:**
- Модель не может перевести 45% фраз бенчмарка
- Для продакшена это неприемлемо
- Но для исследования — это честный результат

**Следующие шаги:**
1. Зафиксировать результат в отчёте
2. Сфокусироваться на других улучшениях (качество перевода для 55% фраз)
3. Искать применения, где 55% достаточно (например, помощь в обучении РЖЯ)

**Оценка:** 100% вероятность, но ограничивает применение

### Вариант E: Альтернативные источники данных

**Идеи:**
1. **VOGinfo** (https://voginfo.ru/) — видео с сурдопереводом, возможно есть разметка
2. **YouTube-каналы на РЖЯ** — найти видео с субтитрами на русском
3. **Словари РЖЯ онлайн** — например, http://www.rsl.ru/ru-3-2.html
4. **Синтез данных** — использовать существующие видео для генерации новых слов (data augmentation)

**Риски:**
- Лицензионная чистота не гарантирована
- Качество разметки может быть низким
- Время на поиск и обработку

**Оценка:** 30% вероятность успеха, неопределённые сроки

## 5. Рекомендация

**Краткосрочно (1-2 недели):**
1. Попытаться получить лицензию на полный каталог SP-10 (Вариант B)

3. Если оба провалятся — записать 50-100 самых частых слов с исполнителями (Вариант C)

**Долгосрочно (1-2 месяца):**
1. Полноценная запись 190 слов с носителями РЖЯ (Вариант C)
2. Интеграция дополнительных источников (Вариант E)

**Если нет ресурсов:**
Принять потолок 55% и сфокусироваться на улучшении качества для доступных фраз (Вариант D).
