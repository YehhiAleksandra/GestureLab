# GestureLab PC v0.1

Прототип этапа 0 из ТЗ «Переводчик жестов» — та же задача, что у Android-версии, но на ПК: быстрее итерировать и отлаживать, в телефон потом перегоним. Формат JSON-сессий **совместим с GestureLab Android v0.1** — данные с ПК и телефона складываются в одну папку и одну сводку.

## Что делает

- Веб-камера (1280×720) → MediaPipe Hands (2 кисти) + Face Detection.
- Окно с живой статистикой: доля кадров с обеими кистями, доля с лицом, FPS, число рук в текущем кадре. Эталон критерия ТЗ (обе кисти ≥ 90%) на экране.
- Запись сессий: только точки рук (21×3 на кисть, нормированные) + флаги по кадрам. Видео **не сохраняется**.
- Скелет рук рисуется поверх превью (можно выключить `--no-preview-landmarks`).

## Установка и запуск

```bash
# Windows: py -3.11; Linux/macOS: python3.11
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt

python gesturelab.py            # камера 0
python gesturelab.py --camera 1 # если несколько камер
```

Клавиши: **r** — старт/стоп записи (жест и исполнитель спросит в консоли), **p** — переключить положение (грудь/шнурок/подставка), **q** — выход.

## Протокол этапа 0 (как в ТЗ)

1. **20 жестов** из словаря v1 (см. `gestures.txt`), **10 повторений** на жест, **2 положения**: «грудь» (камера на груди вперёд, широкоугольная линза) и «шнурок» (камера на шнурке, наклон вверх). Двое исполнителей желательно.
2. Каждое повторение: жест ~1–2 с, пауза ~2 с, сессия 10–20 с. Одна сессия = одно повторение.
3. Камера при записи должна стоять так же, как будет закреплена на теле: прикинь держатель/шнурок, не держи в руке «как удобно».
4. Проверяй отдельно жесты у лица (вопрос, эмоции) — в положении «грудь» они, скорее всего, выпадают из кадра. Если так — в словаре v1 нужны варианты перед телом.

Список жестов: `gestures.txt` (31 фраза словаря v1 — можно брать первые 20 или все сразу).

## Сводка

```bash
python summarize.py sessions/                # по положениям, с вердиктом >=90%
python summarize.py sessions/ --by-gesture   # разрез по жестам
python summarize.py sessions/ --csv report.csv
```

Сессии с Android (папка `sessions` из `adb pull`) кидай в ту же папку — сводка их подхватит.

## Отладочные возможности прототипа

- Всё синхронно и в одном файле — легко ставить `print`/breakpoint рядом с любым кадром.
- `--fps 30` для записи плотнее, `--fps 15` — эталон ТЗ.
- Пороги детекции (`min_detection_confidence=0.5`) лежат в `gesturelab.py` прямо в конструкторах — крути для экспериментов.
- Проверь на старте: если `обе кисти` в покое у тебя на груди уже ~100%, а при жестах проседает — проблема геометрии, не модели.
