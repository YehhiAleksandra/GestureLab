# Полноценный переводчик РЖЯ

## Что сделано

Объединены три датасета для создания полноценного переводчика русского жестового языка:

1. **Slovo** (19600 окон, 1001 класс)
   - 1000 слов/фраз РЖЯ + no_event
   - Включает буквы дактиля (А-Я) и слова (Борода, Выигрыш, 2 часа, и т.д.)
   - Источник: открытый датасет РЖЯ

2. **Bukva** (1675 окон, 34 класса)
   - Только буквы дактиля
   - Добавлены для увеличения объёма данных по буквам

3. **YouTube** (67 окон, 32 класса)
   - Буквы дактиля из видео курса РЖЯ
   - Все буквы уже есть в Slovo, не добавлялись

## Итоговый датасет

- **Файл:** `datasets/combined_full_translator.npz`
- **Всего окон:** 21275
- **Классов:** 1001 (буквы + слова)
- **Train/Val:** 17020 / 4255 (80/20)

## Модель

- **Файл:** `translator_model_full.npz`
- **Архитектура:** GRU (numpy, BPTT + Adam)
- **Параметры:** hidden=64, epochs=50
- **Вход:** 22 кадра × 126 признаков (2 руки × 21 точка × 3 координаты)
- **Выход:** 1001 класс (softmax)

## Использование

### 1. Предсказание слов на видео

```bash
# Обработка видео через MediaPipe
python tools/process_alfavit.py datasets/youtube_ark/holy_sepulchre.mp4 \
  --output datasets/youtube_ark/holy_sepulchre_landmarks.json

# Предсказание слов
python tools/predict_words.py datasets/youtube_ark/holy_sepulchre_landmarks.json \
  --model translator_model_full.npz \
  --output predicted_words.json \
  --min-confidence 0.3
```

### 2. Озвучка предсказанных слов

```bash
python tools/voice_predictions.py predicted_words.json \
  --output voiced_words.mp3 \
  --voice ru-RU-SvetlanaNeural
```

### 3. Создание видео с субтитрами и озвучкой

```bash
# Создание SRT субтитров
# (вручную или скриптом из predicted_words.json)

# Наложение аудио и субтитров
ffmpeg -y -ss 95 -t 30 -i holy_sepulchre.mp4 -i voiced_words.mp3 \
  -filter_complex "[0:v]subtitles=subtitles.srt:force_style='FontSize=20'[v]" \
  -map "[v]" -map 1:a -c:v libx264 -c:a aac -shortest output.mp4
```

## Ограничения

1. **Качество предсказания:** Модель обучена на изолированных жестах из датасета Slovo. Непрерывная связная речь в видео может распознаваться хуже.

2. **Контекст:** Модель предсказывает отдельные слова/буквы, не учитывает контекст и грамматику РЖЯ.

3. **Скорость:** Обработка видео через MediaPipe + предсказание занимает время (зависит от длины видео).
